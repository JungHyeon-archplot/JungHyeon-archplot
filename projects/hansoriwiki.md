# 한소리 위키

동국대학교 풍물소모임 한소리의 문서와 활동을 기록하는 위키입니다. 장정현이 웹 서비스 개발과 운영 기능을 구현하고 있습니다.

[서비스](https://hansoriwiki.pages.dev/) · [프로필로 돌아가기](../README.md)

## 해결하려는 문제

동아리의 사람·문서·활동 기록을 모으고, 구성원에게 필요한 접근 권한과 편집·관리 도구를 제공합니다.

## 구현한 내용

- Google 로그인, 가입 승인, 역할별 접근 제어
- Markdown 문서 작성·편집, 검색과 변경 이력
- 사람·활동 기록과 사진·영상 관리
- 공지·게시판과 운영 관리 화면
- 데이터베이스 권한 정책과 운영 백업
- GitHub Actions 검사·배포와 Cloudflare 서비스 연동

## 사용 기술

| 영역 | 기술 |
| --- | --- |
| 화면 | React, Vite, JavaScript, CSS |
| 인증·데이터 | Supabase Auth, PostgreSQL, RLS, Storage |
| 문서 표시 | Markdown, marked, DOMPurify |
| 배포·미디어 | Cloudflare Pages, Workers, R2 |
| 운영 | GitHub Actions, SQL 마이그레이션, 백업 |

## 개발 경험

사용자 화면과 운영자 기능을 함께 만들고, 화면에서의 접근 제한과 데이터베이스 권한을 연결했습니다. 사진·영상과 기록을 다루면서 회원 승인, 파일 접근, 백업 흐름까지 고려했습니다.

개발·운영 중인 비공개 소스 프로젝트입니다. 이 문서에는 기능과 기술 경험을 요약하며, 구성원 데이터나 내부 운영 정보를 포함하지 않습니다.
